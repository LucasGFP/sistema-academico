# Sistema Acadêmico

## Descrição
Este projeto é uma simulação de um **sistema acadêmico**, focado na prática de controle de versão com **Git**.  
O objetivo é:

- Criar e gerenciar branches (`main` e `feature`)
- Realizar commits temáticos com mensagens descritivas
- Executar merge entre branches
- Simular e resolver conflitos manualmente

O projeto inclui arquivos de exemplo para representar funcionalidades básicas do sistema.

---

## Estrutura do projeto

- `login.py` → simula a tela de login do sistema
- `README.md` → documentação do projeto  

---

## Branches

- **main** → linha estável do sistema  
- **feature-login** → implementação de novas funcionalidades (como validação na tela de login)
